# Salesforce Enterprise Operations Management

A Salesforce portfolio project demonstrating enterprise administration, automation, reporting, dashboards, and custom data modeling.

## Current Module
### IT Help Desk

Built features include:
- Custom Department, Employee, and Support Ticket objects
- Lookup relationships
- Validation rules
- SLA due date automation using Record-Triggered Flow
- Scheduled SLA escalation automation
- Support ticket reporting
- IT Help Desk dashboard
- Ticket workload tracking by technician

## Portfolio Modules

- IT Help Desk
- Security Incident Management
- Employee Onboarding
- Asset Management
- Sales Pipeline CRM
- Database Change Management
